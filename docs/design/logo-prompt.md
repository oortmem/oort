# Logo prompt for Oort

Works in ElevenLabs image generation or any image model. Generate several, pick, then
vectorise the winner (the mark must end up as a clean SVG).

## Primary prompt (mark only)

> Minimal vector logo mark for "Oort", an open-source memory engine for AI agents.
> Concept: the Oort cloud, a faint spherical shell of tiny points surrounding a small
> bright core; a single comet-like point is being pulled inward from the shell toward
> the core, leaving a short thin trail. Geometric, precise, flat vector style, no
> gradients inside the mark, no text, no 3D, no glow effects. One accent colour:
> electric blue (#3B82F6) for the core and the inward-moving point; the shell points in
> soft white (#F5F7FF) on a near-black navy background (#05070F). Generous negative
> space, centred, square composition, readable at 16 pixels. In the spirit of Linear,
> Vercel and Stripe logo marks: restrained, confident, memorable.

## Variant prompts

- **Orbit version**: same brief, but the shell is drawn as two thin elliptical orbit
  rings at different tilts with five to seven points on them, and the core is a solid
  circle; the comet point sits on the inner ring.
- **Monochrome version**: same brief, pure white on near-black, no blue, for favicon and
  terminal use.
- **Wordmark version**: add the word "oort" in a geometric sans (Inter or similar),
  lowercase, medium weight, set to the right of the mark with the mark's height equal
  to the x-height times 1.6. The two o's in "oort" may echo the core and shell but must
  stay legible as letters.

## Negative prompt (if the model takes one)

> no text inside the mark, no glossy or chrome effects, no lens flare, no realistic
> planets, no rocket, no brain icon, no neural network nodes, no gradients, no
> drop shadow, no mockup, no background scene.

## Why this direction

Oort's whole idea is tiering: most memory sits far out and cheap, and a query pulls a
dormant memory back in. The mark should show that one movement, inward, rather than a
generic "space" or "AI" cliché.
