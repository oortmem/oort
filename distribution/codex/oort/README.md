# Oort for Codex

Adds the `oort` memory tools, the `oort-memory` skill, and recall before each prompt. Saving
happens through the `remember` tool. Memories stay on your machine.

Needs the `oort` command (`npm install -g oortmem`, then `oort setup`).

```sh
codex plugin marketplace add oortmem/oort
```

Then install `oort` from that marketplace. More at
[oortcloud.dev/docs/codex](https://oortcloud.dev/docs/codex).
