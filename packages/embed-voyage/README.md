# @oortmem/embed-voyage

Embeddings for Oort through Voyage AI.

```sh
npm install @oortmem/embed-voyage
```

```ts
import { voyageEmbedder } from '@oortmem/embed-voyage';

const embed = voyageEmbedder({ apiKey: process.env.VOYAGE_API_KEY });
```

Part of [Oort](https://github.com/oortmem/oort), open-source memory for AI agents. See the [main README](https://github.com/oortmem/oort#readme) for how the pieces fit. Apache-2.0.
