# @oortmem/rerank-voyage

Reranking for Oort recall through Voyage AI.

```sh
npm install @oortmem/rerank-voyage
```

```ts
import { voyageReranker } from '@oortmem/rerank-voyage';

const rerank = voyageReranker({ apiKey: process.env.VOYAGE_API_KEY });
```

Part of [Oort](https://github.com/oortmem/oort), open-source memory for AI agents. See the [main README](https://github.com/oortmem/oort#readme) for how the pieces fit. Apache-2.0.
